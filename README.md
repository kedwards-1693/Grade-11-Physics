# Grade 11 Physics (SPH3U): Kinematics Review

Interactive review lessons for the Kinematics unit. Each lesson explains the idea in plain language, shows worked examples, and has short knowledge checks with instant feedback.

## Start here

Open **index.html** (or the site link for this repository) and work through the lessons in order.

| Lesson | Topic |
|---|---|
| 0 | Warm-up: units, scientific notation, significant digits, rearranging formulas |
| 1 | Scalars and vectors: distance, displacement, speed, velocity |
| 2 | Position-time graphs |
| 3 | Velocity-time graphs |
| 4 | Instantaneous velocity |
| 5 | Acceleration |
| 6 | The Big Five equations |
| 7 | Gravity and free fall |
| 8 | 2-D vectors |
| 9 | Projectile motion |
| 10 | Lab skills: the two Vernier labs |
| 11 | Review and practice test |

## How to use

- Plan about 60 minutes per lesson.
- Have a calculator, pencil and paper ready.
- Each lesson points to the matching items in Google Classroom. Do those too.
- Type your name once in the yellow bar at the top of a lesson. Your answers and hands-on entries then save online automatically, and you can pick up on any device by typing the same name.
- If online saving is unavailable, progress still saves in the browser on that device.
